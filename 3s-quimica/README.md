## Riscos Identificados

1. Vazamento durante transporte (mitigação: embalagem dupla)
2. Instabilidade química / inchaço (mitigação: pH 11,5–12,5 com NaOH)
3. CAC acima da margem unitária (mitigação: vender kits, não unidades)
